# FlowDesk

Task Management App — TypeScript + SQLite

## Tính năng
- Thêm, xem, hoàn thành, xóa task
- Mức độ ưu tiên: High / Medium / Low
- Deadline cho mỗi task
- Lọc theo trạng thái
- Tìm kiếm theo tên
- Lưu dữ liệu SQLite

## Cài đặt
npm install
npx tsx src/index.ts

## Công nghệ
- TypeScript
- Node.js
- better-sqlite3
